# ADR (Architecture Decision Records)

되돌리기 어렵거나, 나중에 "왜 이렇게 했지?"가 반복될 결정을 한 건씩 기록합니다.
시간순 서사는 [docs/history.md](../history.md), 남은 할 일은 [checkList.md](../../checkList.md)에 있습니다.

## 작성 기준

- **기록할 것**: 대안이 있었고 그중 하나를 골랐으며, 그 이유가 코드만 봐서는 안 드러나는 결정
- **기록하지 않을 것**: 관행대로 한 선택, 되돌리기 쉬운 선택, 코드에 그대로 드러나는 것
- 결정이 뒤집히면 새 ADR을 쓰고 기존 ADR 상태를 `대체됨`으로 바꿉니다. **기존 내용은 지우지 않습니다** — 왜 뒤집혔는지가 기록의 핵심입니다.

## 형식

`NNNN-제목.md`, 아래 네 항목.

```
## 상태      채택됨 | 대체됨(→ ADR-NNNN) | 폐기됨
## 배경      무엇이 문제였는가 (측정값·증상 포함)
## 결정      무엇을 골랐는가
## 결과      얻은 것과 잃은 것, 되돌리는 방법
```
