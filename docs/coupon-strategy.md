# 쿠폰 운영 기준

> 최종 갱신: 2026-09-20
> 대상: 사장님/운영자 + 쿠폰 관리 화면 개발자

배달앱 쿠폰을 어떤 방식으로 발행할지, 그리고 시스템이 실제로 어떻게 계산하는지를 정리합니다.

---

## 1. 지금 시스템이 지원하는 것

| 구분 | 상태 |
|---|---|
| 정액 할인 (`FIXED_AMOUNT`, 예: 3,000원) | ✅ 지원 |
| 정률 할인 (`PERCENTAGE`, 예: 10%) | ✅ 지원 |
| 최소 주문금액 조건 | ✅ 지원 |
| 정률 할인 상한 | ✅ 지원 (기본 5,000원) |
| 총 발급 한도 | ✅ 지원 (발급 수 기준, 관리자 발급·프로모 코드 양쪽 적용) |
| 유효기간 | ✅ 지원 (기본 30일) |
| 프로모 코드로 고객이 직접 등록 | ✅ 지원 |
| **쿠폰을 만드는 어드민 화면** | ✅ `/coupons` 구현 (ADMIN 전용, OWNER 접근 불가) |

어드민 생성·목록·사용자 ID 직접 발급 화면을 구현했고 타입 검사와 모의 API E2E 4개를 통과했습니다. 실제 생성→고객 앱 수신→결제 연동과 배포 확인은 남아 있습니다. [개발 요청서의 검증 현황](prd/admin-coupon-management.md#6-검증) 참고.

총 발급 한도(`maxUses`)는 **이미 발급된 장수** 기준으로 판정하며, 관리자 직접 발급과 프로모 코드 등록 양쪽에 동일하게 적용됩니다 (2026-09-21 보완). 같은 고객에게 같은 쿠폰이 두 번 발급되는 것도 양쪽에서 막습니다.

> 동시 요청이 겹치면 한도를 1~2장 넘길 수 있습니다. 예산 통제 목적에는 충분하다고 보고 별도 잠금은 두지 않았습니다. 엄격히 막아야 하는 프로모션이라면 발급 수 컬럼 + 조건부 증가 방식으로 바꿔야 합니다.

쿠폰 비활성화는 어드민 목록에서 바로 전환할 수 있습니다. 비활성 쿠폰은 신규 발급도, 결제 시 사용도 되지 않습니다. (쿠폰 내용 자체를 수정하는 기능은 아직 없으므로, 조건을 바꾸려면 새 쿠폰을 만들고 기존 쿠폰을 비활성화하세요.)

## 2. 할인 기준: 배달비는 제외

**쿠폰 할인은 상품 금액에만 적용되고, 배달비는 할인되지 않습니다.** (2026-09-20 정책 확정)

```
상품 금액 20,000원 + 배달비 3,000원 = 결제 예정 23,000원
3,000원 쿠폰 적용 → 20,000원에서 차감 → 최종 20,000원
```

이전에는 배달비까지 포함한 23,000원 기준으로 계산돼서, **배달비가 비싼 매장일수록 같은 쿠폰이 더 많이 깎이는** 문제가 있었습니다.

쿠폰의 **최소 주문금액 조건도 상품 금액 기준**입니다. 매장의 최소 주문금액 정책과 기준선이 같습니다.

> 주의: 이 기준은 서버(`delivery-order.service.ts`)와 앱(결제 화면, 쿠폰 선택 목록) 세 곳이 **모두 같아야** 합니다. 한 곳이라도 다르면 서버가 결제 금액 검증에서 주문을 거부합니다.

## 3. 정액 vs 정률 — 정액 권장

| | 정액 (3,000원) | 정률 (10%) |
|---|---|---|
| 비용 예측 | 1장 = 정확히 3,000원 | 주문 금액에 따라 변동 |
| 객단가 영향 | 소액 주문에 체감 혜택이 커 **주문 유도** | 고액 주문일수록 많이 깎임 |
| 상한 관리 | 불필요 | 상한을 안 걸면 손실 위험 |
| 고객 인지 | "3,000원 할인" 즉시 이해 | "10%면 얼마?" 계산 필요 |

**기본은 정액을 권장합니다.** 비용이 예측 가능하고, 객단가가 낮은 주문에 상대적으로 큰 혜택이 가서 주문 전환에 유리합니다.

정률을 쓸 경우 **`maxDiscountAmount`(상한)를 반드시 설정**하세요. 미설정 시 고액 주문에서 할인액이 무한정 커집니다. (현재 기본값은 5,000원)

## 4. 권장 조합 예시

| 목적 | 타입 | 할인값 | 최소 주문금액 | 비고 |
|---|---|---|---|---|
| 신규 고객 첫 주문 | 정액 | 3,000원 | 15,000원 | 최소금액으로 객단가 방어 |
| 재주문 유도 | 정액 | 2,000원 | 12,000원 | 유효기간 짧게(7~14일) |
| 리뷰 이벤트 | 정액 | 1,000~2,000원 | 없음 | 소액·부담 없이 |
| 시즌 프로모션 | 정률 | 10% | 20,000원 | **상한 5,000원 필수** |

설계 시 체크할 것:
- **최소 주문금액 ≥ 매장 최소 주문금액**으로 잡아야 쿠폰 때문에 역마진이 나지 않습니다.
- **총 발급 한도(`maxUses`)** 를 걸어 예산 상한을 고정하세요. 발급된 장수 기준으로 막히므로, 고객이 아직 사용하지 않은 쿠폰도 한도에 포함됩니다.
- 유효기간(`defaultExpiryDays`)이 길수록 미사용 쿠폰이 쌓여 부채처럼 남습니다. 기본 30일.
